# Agent Instructions

When working in this repository, follow these guidelines:

## General principles

- The project is built with React, TypeScript, and Vite.
- New changes should align with the existing structure.
- Components, hooks, services, and types should remain organized in separate folders.
- TypeScript types should be used properly to maintain code quality.

## Coding guidelines

- Keep JSX and TSX files clean, readable, and modular.
- When adding new components, follow the existing design language and styling patterns.
- Prefer reusable components and shared logic where possible.
- Keep the user interface consistent with the dark theme.
- When adding new functionality, include appropriate toast messages and error handling.

## Things to pay attention to

- Keep the core image-processing logic in the service layer.
- Implement UI changes inside components.
- Run build and lint checks after each meaningful change.
- Update package.json properly when adding or removing dependencies.

## Recommended workflow

1. Understand the user's request clearly.
2. Place the change in the most appropriate component or service.
3. Make small and focused updates.
4. Verify with build and lint checks.
5. Summarize the result briefly.
